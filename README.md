# Pneumonia Detection using CNN

## Overview
Deep learning-based pneumonia detection system using CT scan images.

## Technologies
- Python
- TensorFlow/Keras
- Flask
- OpenCV
- NumPy

## Model Architecture
- 5 Convolutional Layers
- Batch Normalization
- Max Pooling
- Dense Layers
- Softmax Output

## Performance
- Accuracy: 99.82%
- Dataset: 5000+ CT scan images

## Run Project

pip install -r requirements.txt
python app.py
